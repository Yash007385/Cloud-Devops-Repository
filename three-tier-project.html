AWS Three-Tier Application

Project Overview

Deployed a Student Registration Application using Amazon S3, EC2 and RDS MySQL. The frontend communicates with a Spring Boot backend, which stores registration data in MySQL.

Architecture

Users / Browser
Amazon S3 - Frontend
Amazon EC2 - Spring Boot API
Amazon RDS - MySQL

AWS Services Used

  • Amazon S3 - Static Website Hosting
  • Amazon EC2 - Backend Hosting
  • Amazon RDS - MySQL Database
  • IAM - Permissions
  • Security Groups - Network Access

Deployment Steps

  1. Created an RDS MySQL database.
  2. Launched an EC2 instance.
  3. Installed Java and Maven.
  4. Built the Spring Boot application.
  5. Connected backend to RDS.
  6. Hosted frontend using Amazon S3.
  7. Tested student registration.

Challenges and Solutions

Resolved database connectivity issues, security group configuration problems and backend application startup errors.

Project Status

Successfully tested during deployment. AWS resources were later removed to manage cloud costs.
